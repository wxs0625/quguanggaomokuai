# v4.41 本版本变更记录

生成时间：2026-08-18
版本定位：在 v4.40 的精简范围基础上，根据两份 2026-08-18 12:40 代理日志，定向修复网易云音乐和汽水音乐开屏广告。

## 问题核对

- README 对应的官方独立模块可正常获取：哔哩哔哩、网易云音乐和抖音模块均返回 `HTTP 200`。
- v4.38 只有哔哩哔哩域名规则，没有官方模块中的 `app.bilibili.com/x/v2/splash` 响应体清理规则。
- v4.38 网易云使用旧版 `ddgksf2013` 23 条脚本，未采用用户单独模块中的广告空响应和 `ipv4.music.163.com` 处理方式。
- v4.38 的共享广告规则直接拒绝 `i.snssdk.com`、`is.snssdk.com`、`security.snssdk.com`、`vas.snssdk.com`、`effect.snssdk.com` 和 `webcast-open.douyin.com`，会误伤抖音正常接口。
- 当前本地 PacketTunnel 日志日期为 2026-08-13，早于本次反馈，因此本版依据当前模块和官方源核对，不把旧日志当作本次设备实测证据。

## 日志确认

- 网易云 `proxy-2026-08-18-124041.db` 和 `proxy-2026-08-18-124053.db` 显示 `xeapi/ad/*` 已命中 v4.40 空响应，但启动阶段仍反复请求 `eapi/link/position/show/resource`；该接口是本次仍出现开屏广告的未处理资源接口。
- 汽水 `proxy-2026-08-18-124041.db` 显示实际主机为 `api3-lq.qishui.com:443`，命中 `GEOIP,CN,DIRECT`；v4.40 只将 `api5-lq.qishui.com` 放入 MITM，故汽水的 `/luna/*` 响应规则没有执行。广告平台 `ads5-normal-hl.zijieapi.com` 已命中拒绝规则。

## 本次处理

1. 为网易云 `xeapi/ad/get` 返回官方脚本使用的 `{"code":200,"ads":{}}` 空广告结构。
2. 将网易云日志确认的 `eapi/link/position/show/resource` 映射为空 JSON，避免启动资源接口继续下发开屏资源。
3. 将汽水所有现有 `api5-lq` 规则扩展到 `api3-lq`，并在 `[MITM]` 补充日志确认的 `api3-lq.qishui.com`。
4. 将网易云和汽水脚本标签更新为 `v441_`，保持旧版本目录不变。
5. 不修改闪动校园、抖音或其它软件规则。

## 预期结果

- 网易云 `xeapi/ad/get` 返回合法空广告结构，`eapi/link/position/show/resource` 返回空对象。
- 汽水 `api3-lq.qishui.com` 进入 MITM 后，现有 `/luna/*` 广告响应规则可以执行。
- 哔哩哔哩、抖音和其它软件规则保持 v4.40 状态。
- 本地只能完成规则、源文件和语法静态校验，不能声称已在 iPhone 上实测通过。
