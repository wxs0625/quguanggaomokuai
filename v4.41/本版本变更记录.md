# v4.41 本版本变更记录

生成时间：2026-08-19

版本定位：基于 v4.40，定向修复抖音“暂停识图”提示无网络连接，不扩大其它 App 的改动范围。

## 问题核对

- 仓库缓存的 fmz200/wool_scripts 抖音独立模块 `.cache/TikTok.lpx` 只拒绝 `bds.snssdk.com` 和 `p3.pstatp.com`。
- 仓库缓存的汽水音乐独立模块 `.cache/fmz_modules/QiShuiMusic.sgmodule` 包含 5 条 `api100-*.amemv.com` 拒绝规则，集成模块完整继承了这些规则。
- `amemv.com` 是抖音与汽水音乐共用域名；这些规则合并后不再只影响汽水音乐，也会拒绝抖音正常 API/QUIC 请求。
- 旧 PacketTunnel 记录确认集成规则曾连续拒绝 `frontier-aweme-*.amemv.com` 一类正常字节传输主机，说明跨应用共享域名确实会被汽水音乐规则命中。
- 本次没有用户刚复现时的新代理日志，因此只能确认静态规则冲突和历史命中，不能声称已在 iPhone 上实测通过。

## 本次处理

1. 在 `[Rule]` 最前保留 v4.39 已确认的 6 个抖音核心域名 `DIRECT` 规则。
2. 将 5 类 `api100-*.amemv.com` 正常 API/QUIC 主机从后续 `REJECT` 调整为前置 `DIRECT`。
3. 删除后方对应的 5 条冲突 `REJECT`，避免同一主机同时存在相反策略。
4. 保留抖音官方模块的 `bds.snssdk.com`、`p3.pstatp.com` 广告拦截。
5. 保留 `/aweme/v*/ad/`、`/api/ad/`、穿山甲及广告素材规则，不放行广告路径或广告平台域名。
6. 其它 App 的 URL Rewrite、Map Local、Body Rewrite、Script 和 MITM 内容均继承 v4.40。
7. 同步更新模块名称、简介、日期、注释和网易云脚本标签为 v4.41。

## 影响范围

- 预期恢复抖音暂停识图所需的 API 传输连接。
- 不对全部 `amemv.com`、`snssdk.com` 或 `zijieapi.com` 做宽泛放行。
- 汽水音乐仍保留专用广告接口、广告素材和广告平台拦截，但不再通过这 5 类抖音共用 API 主机强制断网。
- v4.40 及之前版本目录保持不变。

## 验证结论

- 5 类目标主机只保留前置 `DIRECT`，不存在对应 `REJECT` 残留。
- 抖音官方两条核心广告域名规则仍存在。
- 模块仍保持 URL Rewrite、Map Local、Body Rewrite、Script、Rule、MITM 六个单一段落。
- v4.41 不包含 `v440_` 脚本标签。
