# v4.8 本版本变更记录

日期：2026-08-13

## 本版本文件

- `全能去广告修复版-Shadowrocket-v4.8.sgmodule`

## 改动背景

- 用户反馈：闪动校园打开显示“无网络连接”。
- 用户反馈：百度网盘开启屏广告依然存在。

## 改动摘要

- 从 `v4.7` 复制生成 `v4.8` 主模块文件。
- 闪动校园改为保守兼容模式：不再对主业务域名 `api.huachenjie.com` 做 HTTPS MITM 和 Map Local 改写。
- 保留闪动校园外部广告 SDK 处理：`ad.shunchangzhixing.com`、`open.e.kuaishou.cn`、`zlsdk.1rtb.net`。
- 百度网盘补强开屏广告拦截，新增 `pan.baidu.com` 活动入口、会员弹层、`pcs/adx`、`update.pan.baidu.com/statistics`、`ndstatic.cdn.bcebos.com/activity/welfare/js/` 等规则。
- 旧版本目录不删除，继续保留 `v4.0` 至 `v4.7`。

## 闪动校园修复说明

- v4.7 中 `api.huachenjie.com` 被加入 MITM 主机列表，且主业务接口被 Map Local 改写。
- 这类主业务域名一旦触发证书校验或接口结构变化，App 可能表现为“无网络连接”。
- v4.8 取消对 `api.huachenjie.com` 的改写，优先恢复 App 正常联网。
- 去广告只保留在外部广告 SDK 域名上，降低误伤主业务接口的风险。

## 百度网盘补强说明

- v4.7 已有 `issuecdn.baidupcs.com/issue/netdisk/guanggao` 和 `ts_ad` 规则。
- v4.8 继续补充百度网盘开屏、活动入口、会员/福利弹层和广告统计接口。
- 如果 App 已缓存旧开屏图，更新模块后可能需要清理百度网盘缓存或等待缓存过期。
