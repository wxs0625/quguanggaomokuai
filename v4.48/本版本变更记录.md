# v4.48 本版本变更记录

生成时间：2026-08-19

版本定位：基于 v4.47，将抖音处理收缩为仅拦截开屏广告，停止对抖音其它请求进行去广告、改写、MITM 或历史直连补丁处理，以解决暂停后“识物”提示无网络。

## 问题核对

- v4.41 至 v4.47 持续依据日志为不同的抖音/字节主机添加 `DIRECT`，但用户仍复现识物无网络。
- v4.47 同时保留 URL Rewrite、Map Local、Body Rewrite、Script、Rule 和 MITM 中的大量字节系广告拦截项；新增的直连规则只能覆盖已出现的主机，无法保证后续接口不会再次命中其它共享拒绝规则。
- 上游 `fmz200/wool_scripts` 的独立抖音模块仅使用两条规则：`DOMAIN-KEYWORD,bds.snssdk.com,REJECT` 与 `DOMAIN-KEYWORD,p3.pstatp.com,REJECT`。

## 本次处理

1. 移除所有非汽水音乐专属的抖音/字节系 URL Rewrite、Map Local、Body Rewrite 和 Script 处理。
2. 移除所有历史抖音识物 `DIRECT` 补丁，包括 `log.snssdk.com`、`dig.bdurl.net`、`frontier-aweme`、`vcs.zijieapi.com`、`bytegecko` 和资源签名主机。
3. 移除规则段中会匹配抖音/字节链路的共享拒绝项，以及 MITM 中相应的非汽水音乐主机。
4. 抖音仅保留上游两条开屏广告规则：`DOMAIN-KEYWORD,bds.snssdk.com,REJECT`、`DOMAIN-KEYWORD,p3.pstatp.com,REJECT`。
5. 保留汽水音乐仅匹配 `qishui.com` 与 `beta-luna.douyin.com/luna/` 的规则；移除会与抖音共用的 TNC、`webcast-open.douyin.com` 等处理。
6. 其它非字节系 App 的规则、脚本与 MITM 项目均继承 v4.47。

## 影响与验证

- 因穿山甲/巨量等广告平台域名与抖音共用，为保证抖音不再被共享规则拦截，本版本不再通过这些共享字节域名拦截广告；依赖这些通用域名的其它 App 可能少拦截一部分广告。
- 模块包含 URL Rewrite、Map Local、Body Rewrite、Script、Rule、MITM 六个配置段。
- 在 Rule 段中，抖音相关拒绝规则仅剩上游两条开屏规则；没有抖音相关 `DIRECT`、URL 改写、脚本或 Body Rewrite。
- 已完成配置静态核对；当前环境不能替代 iPhone 上的暂停识物实际测试。
- v4.47 及之前版本目录未修改。
