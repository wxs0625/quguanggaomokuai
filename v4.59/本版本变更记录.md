# 全能去广告精简范围恢复版 v4.59 变更记录

- 基线版本：v4.58（= v4.57 + 闲鱼商品详情页相关推荐恢复）
- 发布日期：2026-08-28
- 问题现象：闲鱼"我的"页面、订单页面以及首页、同城、关注等多处正常内容大量缺失。

## 根因分析

模块中存在大量**白名单式重写**（`map(select(...))` 只保留少数模板名/类型，其余全部删除）。闲鱼 App 更新接口结构或模板命名后，白名单匹配不到新字段，正常内容被整段过滤。此外"我的"页、首页信息流等还被 `goofish.js` 脚本二次白名单过滤，双重误删。

## 修复内容

### [Body Rewrite] 删除的白名单规则（10 条）

| 接口 | 原规则行为 |
| --- | --- |
| `mtop.idle.user.page.my.adapter` | 只保留 5 个模板名 + 工具栏按 id 白名单重排（"我的"页内容缺失主因） |
| `mtop.taobao.idle.trade.full.info` | 只保留 orderStatusVO/addressInfoVO/orderInfoVO 三种组件（订单页内容缺失主因） |
| `mtop.taobao.idle.fun.follow.feed.list` | 只保留 cardType==2001（关注页） |
| `mtop.taobao.idlehome.home.community` | 只保留 2 种模板名（社区页） |
| `mtop.taobao.idle.local.home` | 只保留 cardType=="common"（同城页） |
| `mtop.taobao.idle.local.home.top` | 只保留 1 种组件 key |
| `mtop.taobao.idle.local.flow.plat.section` | 只保留 fish_city_kingkong 模板 |
| `mtop.taobao.idle.home.whale.modulet` | 只保留 fish_home_miniapp 模板 |
| `mtop.taobao.idlehome.widget.refresh.get` | homeTopList 只保留 kingkongDo |
| `mtop.taobao.idlehome.home.circle.list` | headList 按 bizCode 白名单过滤 |

### [Body Rewrite] 改为黑名单式（保留广告过滤，不再误删）

- `home.nextfresh`（首页信息流）：仅清除 `homeMultiBanner`/`mamaAD`/`AD` 广告卡片，删除模板名白名单。
- `home.newitem.page`、`idlemtopsearch.search`：为缺失路径补充空值保护，避免整段过滤报错或误删。

### [Script] 移除的 goofish.js 条目（4 条，均为白名单二次过滤）

- 商品信息流广告（nextfresh，只留 cardTypeValue=="Item" 并清空顶部菜单）
- 个人主页（my.adapter，只留 index 0/1/3 + 工具栏标题白名单）
- 首页顶部频道菜单（circle.list，只留 circleId 1/2）
- 同城页横幅广告（flow.plat.section）

### [Script] 保留但锚定匹配（3 条，黑名单逻辑安全）

- 定位地区页面的信息流广告、商品详情页周边推荐、搜索结果信息流广告：模式加版本段结尾锚定，避免前缀误匹配。

## 保留内容

- 全部开屏广告拦截（含闲鱼 `idlecommerce.splash` 请求级拦截）。
- 闲鱼广告字段清空类黑名单规则（bannerList、recommends 等）。
- `PROTOCOL,QUIC,REJECT` 全局 QUIC 阻断与其他全部应用规则。
