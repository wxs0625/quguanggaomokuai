# v4.59 变更记录

## 版本：全能去广告精简范围恢复版 v4.59
## 日期：2026-08-26

## 核心修复：MITM hostname 覆盖缺口

v4.58 虽然新增了 180+ 广告 SDK 域名的 DOMAIN-SUFFIX REJECT 规则，但冷启动第一次开屏广告仍然漏过。
经审计发现根因是 **MITM hostname 覆盖缺口**：大量 URL Rewrite/Map Local/Body Rewrite/Script 规则引用的域名不在 MITM hostname 列表中，导致 HTTPS 流量无法被解密，这些规则全部失效。

### 修复内容

#### 1. 修正搜狐域名拼写错误（严重）
- MITM hostname 中原来是 `*.souhu.com`（多了字母 u）
- 正确应为 `*.sohu.com`
- 此错误导致所有搜狐系广告规则（agn.aty.sohu.com、m.aty.sohu.com、mmg.aty.sohu.com、hui.sohu.com、photocdn.sohu.com、pic.k.sohu.com、s.go.sohu.com、api.k.sohu.com）全部失效

#### 3. 修复过于宽泛的 DOMAIN-SUFFIX REJECT 规则
以下域名全盘 REJECT 会破坏 App 正常功能，改为只拦截广告相关子域名：
- `youdao.com` → 拆分为 `dsp-impr2.youdao.com`、`clkservice.youdao.com` 等子域名
  - youdao.com 是有道词典主域名，全盘 REJECT 会破坏查词功能
- `gdtimg.com` / `gtimg.cn` / `qq.cn` → 拆分为 `adsmind.gdtimg.com`、`gdt.gtimg.cn` 等
  - 这些是腾讯 CDN 域名，全盘 REJECT 会影响 QQ音乐、游戏等
- `umeng.com` / `umengcloud.com` → 改为只拦截 `ulogs.umeng.com` 等广告推送子域名
- `talkingdata.com` → 改为只拦截 `analytics.talkingdata.com`
- `tenddata.com` → 改为只拦截 `applog.tenddata.com`

#### 4. 移除 coolapk/weibo 的 DIRECT + MITM 排除
- 酷安（coolapk.com）：原来设为 DIRECT（不走代理）+ MITM `-` 排除 = 完全无法拦截 HTTPS 广告
  - 移除 `DOMAIN,api.coolapk.com,DIRECT` 等规则
  - 移除 MITM hostname 中的 `-api.coolapk.com`、`-www.coolapk.com`、`-coolapk.com`、`-*.coolapk.com`
  - 现在 coolapk 流量走代理 + MITM 解密，URL Rewrite 规则可生效
- 微博（weibo.com）：同样设为 DIRECT + MITM 排除
  - 移除 `DOMAIN,api.weibo.cn,DIRECT` 等 7 条 DIRECT 规则
  - 移除 MITM hostname 中的 `-weibo.com`、`-*.weibo.com`、`-api.weibo.cn` 等 13 条排除项
  - 现在 `api.weibo.cn/2/ad/preload`（开屏广告预加载）的 URL-REGEX REJECT-DROP 规则可以生效
  - sina 相关排除项保留（sina.cn/sina.com.cn 等主要是新闻和图片 CDN，不直接返回广告）
