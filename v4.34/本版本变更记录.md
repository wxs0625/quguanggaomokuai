# v4.34 本版本变更记录

生成时间：2026-08-16  
版本定位：单文件集成修复版，目标是把用户确认“单独运行可用”的转转、虎牙直播、腾讯视频、网易云音乐规则合并到一个 Shadowrocket 模块里使用。

## 本次核心修复

1. 基于 v4.32 继续保留主模块的其它 App 去广告规则，没有拆成多个模块。
2. 重新集成转转规则：
   - 将 Loon `[Rewrite]` 里的 `reject-dict` 转换为 Shadowrocket `[Map Local]` JSON 空响应。
   - 将 `response-body-replace-regex` 转换到 Shadowrocket `[Body Rewrite]`。
   - 将 Loon `[Script]` 写法转换为 Shadowrocket `[Script]` 写法，并去掉 Loon 参数开关依赖。
3. 重新集成虎牙直播规则：
   - 保留单独模块的开屏广告域名 `[Rule]` 拦截。
   - 将 `reject`、`reject-img`、`reject-dict` 分别转换到 Shadowrocket 可识别的 `[URL Rewrite]` / `[Map Local]`。
4. 重新集成腾讯视频规则：
   - fmz200 当前 Loon 文件中的腾讯视频拦截规则全部是注释状态。
   - v4.34 将这些注释规则激活，并转换为 Shadowrocket 规则，否则集成后不会实际拦截。
5. 重新集成网易云音乐规则：
   - 使用用户上传的单独可用 Shadowrocket 模块作为来源。
   - 将所有重复的 `netease.adblock` 脚本名重命名为 `v434_网易云_ddgksf_01` 至 `v434_网易云_ddgksf_23`，避免集成模块中脚本同名覆盖。
6. 重新生成 `[MITM]`：
   - 只保留一个 MITM 段。
   - 将转转、虎牙直播、腾讯视频、网易云音乐关键 host 前置。
   - 合并 v4.32 原有 host，避免后续规则失去解密匹配能力。

## 为什么之前单独模块有效、集成后失效

- Loon 的 `[Rewrite]` / `[Script]` 语法不能原样塞进 Shadowrocket `.sgmodule`。
- 网易云音乐单独模块里存在大量同名 `netease.adblock`，单独运行时问题不明显，集成后更容易被后面的同名脚本覆盖。
- 多个模块各自带 `[MITM]` 时，直接拼接可能导致只有最后一个或部分 host 生效。
- 腾讯视频源文件当前有效拦截规则本身是注释状态，简单拼接不会起作用。

## 使用建议

1. 在 Shadowrocket 中删除旧的 v4.32 / v4.33 测试模块。
2. 导入 v4.34 单文件模块。
3. 打开 HTTPS 解密，并确认已信任证书。
4. 对转转、虎牙直播、腾讯视频、网易云音乐先清理 App 缓存或重装后再测开屏广告。
