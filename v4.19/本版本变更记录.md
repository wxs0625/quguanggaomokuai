# v4.19 本版本变更记录

## 版本定位

- 版本：v4.19
- 日期：2026-08-13
- 文件：全能去广告修复版-Shadowrocket-v4.19.sgmodule
- 基线：v4.18/全能去广告修复版-Shadowrocket-v4.18.sgmodule
- 用户反馈：v4.18 仍然有开屏广告，要求一步到位。
- 目的：从小步空响应升级为强力去开屏广告版本，回收广告 SDK 直连白名单，并在规则层硬拦截开屏素材域。

- v4.17 已处理 shunchangzhixing base/getAd，v4.18 已处理多个广告 SDK 的响应层，但仍有开屏广告。
- 继续只补单个接口已经不够；v4.19 改为优先阻断广告 SDK 域名本身。
- 为避免回到“无网络/闪退”，v4.19 仍保留主业务与基础启动链路：
  - api.huachenjie.com
  - oss-cdn.huachenjie.com
  - api-cfg.8ziben.com
  - hzjizhun.cn
  - getui.com / getui.net / gepush.com
  - umeng / amap 日志类稳定链路
- v4.19 不再保留第三方广告 SDK 的 DIRECT 白名单。

## 风险说明

- v4.19 是强力版：比 v4.18 更可能去掉广告，但也比 v4.18 更可能影响部分广告 SDK 初始化。
- 如果 v4.19 出现闪退，说明广告 SDK 初始化与启动强耦合，需要退回 v4.18 并用新日志精确定位漏掉的展示域。
- 如果 v4.19 能稳定进入但仍有广告，必须提供 v4.19 的 PacketTunnel 日志；继续盲改无法确认真实展示来源。
