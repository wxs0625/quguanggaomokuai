# v4.55 本版本变更记录

生成日期：2026-08-25

## 版本目的

修复闲鱼（Goofish）开屏广告在 v4.54 修复后仍然间歇性复发的问题。通过闲鱼代理日志分析发现，开屏广告的根因是：
1. 闲鱼 QUIC 流量绕过 MITM（Shadowrocket 无法解密 QUIC 协议）
2. 外部分流规则集（如「国内直连」）将 `goofish.com` 设为 DIRECT，导致依赖 MITM 的 URL Rewrite/Map Local/Body Rewrite/Script 规则全部失效

## 本次改动

1. 新增闲鱼/淘宝 QUIC 协议阻断。
   - `AND,((PROTOCOL,QUIC),(DOMAIN-SUFFIX,taobao.com)),REJECT-DROP`
   - `AND,((PROTOCOL,QUIC),(DOMAIN-SUFFIX,goofish.com)),REJECT-DROP`
   - 阻断 QUIC 后 App 回退到 TCP(TLS)，使 MITM 能正常解密 HTTPS 流量，URL Rewrite/Map Local/Body Rewrite 规则恢复生效。
   - 参照小红书的 QUIC 阻断模式 `AND,((PROTOCOL,QUIC),(DOMAIN-SUFFIX,xiaohongshu.com)),REJECT`。

2. 新增闲鱼请求级开屏广告拦截（不依赖 MITM）。
   - `URL-REGEX,"^https?:\/\/(g-)?acs\.m\.goofish\.com\/gw\/mtop\.taobao\.idlecommerce\.splash(?:\.ads)?(?:\/|\?|$)",REJECT-DICT`
   - `URL-REGEX,"^https?:\/\/(g-)?acs\.m\.goofish\.com\/gw\/mtop\.taobao\.idle\.home\.splash",REJECT-DICT`
   - `URL-REGEX,"^https?:\/\/acs\.m\.taobao\.com\/gw\/mtop\.taobao\.idlecommerce\.splash(?:\.ads)?(?:\/|\?|$)",REJECT-DICT`
   - 在 [Rule] 段添加，即使外部分流将 goofish.com 设为 DIRECT，这些 URL-REGEX 规则仍能在路由阶段拦截广告请求。
   - 同时覆盖 `acs.m.goofish.com`、`g-acs.m.goofish.com` 和 `acs.m.taobao.com` 三个可能的主机名。
   - 使用 REJECT-DICT 返回空 JSON `{}`，避免 App 因请求完全失败而弹出无网络提示。

3. 新增闲鱼广告域名拦截。
   - `DOMAIN,adashx.m.taobao.com,REJECT`
   - `DOMAIN,adash.man.aliyuncs.com,REJECT`
   - 这两个域名在 [Rule] 段拦截，不依赖 MITM。
   - `adashx.m.taobao.com` 原本已有 DOMAIN REJECT（line 2826），确认保留。
   - `adash.man.aliyuncs.com` 原本已有 DOMAIN REJECT（line 2866 区域），确认保留。
   - 此处为显式声明，确保闲鱼广告调度请求被拦截。

4. 保留原有模块内容。
   - 未删除或修改 v4.54 及之前版本的任何规则。
   - 闲鱼原有的 URL Rewrite（reject-dict）、Map Local（空JSON）、Body Rewrite（jq脚本）、Script 段规则全部保留。
   - MITM hostname 中的 `acs.m.goofish.com`、`g-acs.m.goofish.com` 保留不变。

## 风险控制

- QUIC 阻断仅影响 taobao.com 和 goofish.com 的 QUIC 协议流量，TCP/TLS 流量不受影响。
- 阻断 QUIC 后 App 自动回退到 TCP(TLS)，正常业务请求不受影响。
- 请求级 URL-REGEX 规则使用 REJECT-DICT 返回空 JSON，而非 REJECT-DROP 完全丢弃，避免 App 弹出无网络提示。
- 广告域名拦截使用 DOMAIN 级别精确匹配，不影响正常业务域名。

## 日志分析依据

- 闲鱼代理日志中 `acs.m.taobao.com` 的 `mtop.common.getTimestamp` 请求走 DIRECT（正常）。
- `amdc.m.taobao.com/amdc/mobileDispatch`（闲鱼UA）被 REJECT 拦截（正常）。
- `h-adashx.ut.taobao.com:443` 和 `atoken.m.taobao.com:443` 被 REJECT 拦截（正常）。
- `idlecommerce.splash.ads` 请求**未出现在日志中** → 闲鱼可能通过 QUIC 加载开屏广告绕过 MITM，或使用了新的广告接口。
- 日志中触发了 `DOMAIN-SUFFIX,goofish.com,DIRECT` → 此规则不在本模块任何版本中，来自外部分流规则集。
- v4.54 中无 taobao/goofish 的 QUIC 阻断规则（仅有 Apple ASN 714/6185 和小红书 xiaohongshu.com 的 QUIC 阻断）。
