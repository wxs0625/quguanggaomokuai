# v4.49 本版本变更记录

生成时间：2026-08-19

版本定位：基于 v4.48，针对京东部分小模块无网络、内容加载不出来的问题，回退京东部分到上游 `fmz200/wool_scripts` 的基础实现。

## 问题核对

- 上游独立京东模块只包含基础广告域名规则、京东直播小窗重写、一个京东响应脚本，以及 `api.m.jd.com`、`dns.jd.com` 两个 MITM 主机。
- v4.48 在整合本地模块时额外加入了 3 条京东 URL Rewrite、7 条 Map Local 伪空响应、5 条京东 Body Rewrite、1 条与上游脚本同请求范围的重复脚本、6 条额外京东域名拒绝和 4 个额外 MITM 主机。
- 其中 `basicConfig` 的 Body Rewrite 会改写京东 socket 与 HTTPDNS 配置，Map Local 会直接返回空内容；这些处理可能让依赖组件配置、推荐、搜索或小组件数据的请求无法正常完成。

## 本次处理

1. 保留上游京东直播小窗规则：`functionId=getWidgetV1052`。
2. 删除京东额外的 `ms.jr.jd.com`、`dsp-x.jd.com`、搜索词和推荐接口重写。
3. 删除京东全部 Map Local 伪空响应，恢复启动图、读书弹窗、组件配置和广告接口的原始响应链路。
4. 删除京东 `lite_advertising`、`lite_SmartPush` 和 `basicConfig` Body Rewrite，不再改写 socket monitor 或 HTTPDNS 开关。
5. 删除与上游京东脚本完全重叠的 `JD_remove_ads.js`，避免两个脚本同时修改同一响应；保留上游 `jingdong.js`。
6. 删除额外的 `dgstatic.jd.com`、`jdqd.jd.com`、`dsp-x.jd.com`、`im-x.jd.com`、`xlog.jd.com`、`janapi.jd.com` 和 `jddebug` 诊断 URL 拒绝；保留上游京东基础广告规则。
7. MITM 中京东部分只保留上游的 `api.m.jd.com`、`dns.jd.com`，移除读书、京东云、广告素材等额外主机。
8. 其它 App 规则、脚本和配置继承 v4.48，未修改抖音的仅开屏广告策略。

## 验证结论

- 京东部分已与上游 `JD.com.sgmodule` 的基础规则逐项对照。
- 京东不再包含额外 Map Local、Body Rewrite 或重复京东响应脚本。
- 京东 MITM 主机仅保留 `api.m.jd.com`、`dns.jd.com`；京喜脚本仍作为独立京喜规则保留。
- 六个配置段仍完整存在：URL Rewrite、Map Local、Body Rewrite、Script、Rule、MITM。
- 已完成本地静态验证；当前环境无法替代 iPhone 实机验证京东每个小模块。
- v4.48 及之前版本目录未修改。
