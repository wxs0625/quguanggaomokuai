# v4.12 本版本变更记录

日期：2026-08-13

## 本版本文件

- `全能去广告修复版-Shadowrocket-v4.12.sgmodule`

## 用户反馈

- `v4.7`：闪动校园可以进入软件，但进入后无网络。
- `v4.8` 以后：闪动校园主要表现为启动页卡住或闪退。
- 需要停止继续猜接口返回，先核对清楚原因并给出可静态验证的稳定版本。

## 原因核对

- `v4.7` 的无网络原因：模块改写了 `api.huachenjie.com` 主业务接口，尤其是 `/run-front/ad` 等接口，当前 App 版本可能把这些接口当作启动或首页必要数据，返回空数组后会表现为进入后无网络或数据异常。
- `v4.8` 以后闪退原因：虽然逐步移除了 `api.huachenjie.com` 的主业务改写，但仍保留或新增了启动广告 SDK 的拦截、假响应、脚本处理或 MITM，App 启动阶段广告 SDK 失败时可能直接卡启动页或闪退。
- `DIRECT` 不是彻底放行：`DIRECT` 只决定连接走直连，不会自动跳过 `[URL Rewrite]`、`[Map Local]`、`[Script]` 或 `[MITM]`。因此前几个版本仅加 `DIRECT` 仍不足以保证稳定。

## 本版本策略

- 不再猜闪动校园接口返回结构。
- 不再对闪动校园核心域名和高风险启动 SDK 做拒绝、改写、脚本处理或 MITM。
- 只保留顶部 `DIRECT` 白名单，使这些流量在规则层面走直连。
- 其他 App 的去广告规则尽量保留，但涉及闪动校园启动链路的通用 SDK 规则先暂停。

- 从 `[URL Rewrite]` 移除风险改写规则：`15` 条。
