# v4.28 本版本变更记录

生成时间：2026-08-16

## 本次问题

用户反馈：v4.26 脚本段仍显示 v4.25 标签；转转闪退；抖音联网异常；虎牙直播、腾讯视频、优酷、网易云音乐仍有开屏广告。用户要求参考 fmz200/wool_scripts 的规则列表，并撤销本次对抖音的修改。

## 原因确认

1. v4.26 虽然把脚本 Raw 路径从 v4.25 改成了 v4.26，但继承的脚本段注释仍保留 `v4.25 generic cleanup`，所以用户看到脚本里还有 v4.25。
2. v4.26 新增的通用响应体净化过宽，尤其对转转和抖音/字节类接口风险较高，可能造成缺字段、接口校验失败、闪退或联网异常。
3. 虎牙直播、腾讯视频、优酷、网易云音乐的开屏广告更适合使用 fmz 分应用规则和精确空响应，而不是套全局通用净化脚本。

## 本版本策略

1. 基于 v4.25 稳定底座重建 v4.28，不沿用 v4.26 的高风险通用净化逻辑。
2. 删除本地 `通用广告字段净化.js` 相关引用；v4.28 不再引用 `/main/v4.25/` 或 `/main/v4.26/` 的本地净化脚本。
3. 撤销 v4.26 对抖音新增的宽泛规则：不再新增 `byte-clean`、宽泛 `snssdk/amemv/aweme/douyin` 响应体脚本，也不新增宽泛抖音 MITM host。
4. 参考 fmz200/wool_scripts 的分应用规则，补强虎牙直播、腾讯视频、优酷、网易云音乐、微信公众号等精确接口。
5. 对转转保守处理：去掉本地通用净化脚本，仅保留 fmz / 既有精确接口，降低闪退风险。

## 本版本改动

1. 新建 `v4.28/` 目录，保留旧版本不删除。
2. 新增/保留虎牙直播精确开屏接口：`cdn.wup.huya.com`、`business.msstatic.com`、`cdnfile1.msstatic.com`、`live-ads.huya.com`。
3. 新增腾讯视频精确接口：`vv.video.qq.com/(diff|get)vmind`。
4. 新增优酷精确开屏/弹窗接口：`acs.youku.com`、`push.m.youku.com`、`un-acs.youku.com` 相关接口。
5. 新增网易云音乐精确接口：`ipv4.music.163.com`、`interface*.music.163.com` 的广告、发现页、推荐页、评论楼层等接口。
6. 新增微信公众号精确接口：`mp.weixin.qq.com/mp/cps_product_info?action`。
7. MITM 仅补入上述应用必要域名，未新增 v4.26 的宽泛抖音 MITM。
