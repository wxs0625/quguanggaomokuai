# v4.50 本版本变更记录

生成时间：2026-08-19

版本定位：基于 v4.49，修复京东小组件加载缓慢和汽水音乐切换模式时提示网络错误的问题。

## 问题核对

- v4.49 已移除京东组件的空响应和重复脚本，小组件恢复加载；但仍继承上游 `dns.jd.com`、对应 IPv4 和 IPv6 地址的拒绝规则，京东需要回退解析时会出现加载慢。
- 汽水音乐当前同时对 `beta-luna.douyin.com/luna/` 和 `qishui.com/luna/` 的会员、活动、播放器卡片、更多面板、播放历史等接口进行空响应或响应改写。
- “切换模式”需要正常取得模式和播放器配置；在无日志可精确定位时，不能继续保留会改写这些非广告接口的规则。

## 本次处理

1. 删除京东 `dns.jd.com` 的拒绝规则及对应 IPv4、IPv6 拒绝规则，恢复京东 HTTPDNS 请求。
2. 从 MITM 移除 `dns.jd.com`，让京东使用应用自身的正常解析链路，减少小组件首次加载的回退等待。
3. 删除汽水音乐全部 `beta-luna.douyin.com/luna/` 处理，以及 `qishui.com` 的会员、活动、宝箱、播放器卡片、更多面板和播放历史处理。
4. 删除汽水音乐 `SodaMusic_remove_ads.js` 播放历史响应脚本，避免修改模式切换可能共用的响应数据。
5. 汽水音乐只保留一条明确广告接口拦截：`^https:\/\/(api|api5-lq)\.qishui\.com\/luna\/ads\/ - reject-dict`。
6. 从 MITM 移除 `beta-luna.douyin.com`；保留 `api.qishui.com` 与 `api5-lq.qishui.com`，仅供上述精确广告接口规则使用。
7. 京东其它上游基础广告规则、京东脚本和直播小窗规则保持不变；抖音仍只保留两条开屏广告规则。

## 影响与验证

- 京东 HTTPDNS 恢复后，小组件加载预期更快；少数基于 HTTPDNS 的请求可能不再完全受本地规则控制。
- 汽水音乐将不再拦截会员、活动、推荐卡片、播放页面和模式配置相关内容，优先保证模式切换联网；这些位置可能重新出现部分非开屏推广内容。
- 汽水音乐仅剩一条路径精确、名称明确的广告接口拦截，未对整个域名或泛路径做阻断。
- URL Rewrite、Map Local、Body Rewrite、Script、Rule、MITM 六个配置段仍完整存在。
- 已完成静态核对；当前环境不能替代 iPhone 实机测试京东组件加载速度和汽水音乐模式切换。
- v4.49 及之前版本目录未修改。
