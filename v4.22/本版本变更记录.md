# v4.22 - 微博/酷安联网与广告平衡修复版

- 日期：2026-08-13
- 文件夹：v4.22/
- 模块文件：v4.22/全能去广告修复版-Shadowrocket-v4.22.sgmodule
- 本次依据：v4.20 可缓解无网络但广告变多，v4.21 恢复广告拦截后又变成无网络。
- 基线版本：v4.20，保留其关闭微博/酷安深度重写和排除 MITM 的联网稳定策略。

## 核心判断

- v4.21 无网络来自恢复了微博/酷安 41 条深度重写、Map Local 和远程脚本净化。
- v4.20 广告变多来自顶部过宽 DOMAIN-SUFFIX DIRECT，绕过后续广告域 REJECT。
- v4.22 保留 v4.20 的关闭深度重写防无网络，但撤销整域提前直连，并把广告域 REJECT 放在核心业务 DIRECT 前。

## 本版改动

- 从 v4.20 重新生成 v4.22，不继承 v4.21 恢复深度重写导致无网络的逻辑。
- 移除 v4.20 顶部过宽整域直连：weibo/sina/coolapk 等整域 DIRECT。
- 保留微博/酷安深度重写禁用：URL Rewrite、Body Rewrite、Map Local、Script 对应规则仍注释 50 条。
- 保留微博/酷安 MITM 排除，降低 HTTPS 改写和证书校验造成无网络的概率。
- 新增顶部广告域优先拦截，然后仅精准直连核心业务域：api.weibo、mapi.weibo、weibointl.api.weibo、m.weibo、api.coolapk、www.coolapk、coolapk.com。

## 验证结果

- v4.22 版本头已更新。
- 顶部不再存在 v4.20 的微博/酷安整域 DOMAIN-SUFFIX DIRECT。
- 微博/酷安广告域 REJECT 位于核心业务 DIRECT 之前。
- 微博/酷安深度重写仍保持禁用 50 条，避免回到 v4.21 的无网络状态。
- 闪动校园相关规则未改动。

## 风险说明

- 本版优先在“联网可用”和“广告不过多”之间取平衡。
- 因关闭深度响应净化，微博/酷安内嵌在正常 API 响应里的少量信息流广告可能仍存在，但不应再像 v4.20 那样大量放出广告域请求。
