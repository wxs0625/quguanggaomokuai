# v4.23 - 微信公众号广告加强修复版

- 日期：2026-08-13
- 文件夹：v4.23/
- 模块文件：v4.23/全能去广告修复版-Shadowrocket-v4.23.sgmodule
- 脚本文件：v4.23/微信公众号去广告.js
- 本次依据：用户反馈微信公众号仍有广告。
- 基线版本：v4.22，保留微博/酷安联网与广告平衡策略，保留闪动校园既有规则。

## 核心判断

- 原模块已有 mp.weixin.qq.com/mp/getappmsgad 接口拦截，但公众号广告仍可能从文章 HTML 内嵌变量、底部广告区域、CPS 商品、相关阅读和 masonryfeed 等接口出现。
- 只拦 getappmsgad 不足以覆盖公众号正文内嵌广告和推荐广告位。
- 本版不整域屏蔽 mp.weixin.qq.com，避免公众号正文打不开；只加强广告接口和 HTML 响应净化。

## 本版改动

- 新增微信公众号广告域优先拦截：ad.weixin.qq.com、wxsnsdy.wxs.qq.com、wxsnsdythumb.wxs.qq.com。
- 新增 mp.weixin.qq.com 广告接口 URL-REGEX 兜底：getappmsgad、appmsgad、advertisement、masonryfeed、relatedarticle、relatedsearchword、cps_product_info、jsmonitor。
- 新增 Map Local 空响应：getappmsgad 返回空广告结构；CPS、相关阅读、搜索词和瀑布流推荐返回空对象。
- 新增本地脚本“微信公众号去广告.js”，用于净化公众号文章 HTML 和 JSON 响应中的 advertisement_info、app_msg_ad_info、CPS、广告 DOM 区块。
- 保留 mp.weixin.qq.com 的 MITM，以便脚本和 Map Local 能命中公众号文章广告。

## 验证结果

- v4.23 版本头已更新。
- 微信公众号广告域 REJECT 位于 Rule 顶部。
- mp.weixin.qq.com 广告接口同时具备 Rule、URL Rewrite、Map Local 和 Script 四层处理。
- 本地脚本路径已写入模块，并使用 GitHub Raw 链接。
- 微博/酷安 v4.22 折中规则未改动，闪动校园相关规则未改动。

## 风险说明

- 本版只加强公众号广告，不处理微信小程序内所有广告。
- 如果仍有广告，需要提供出现广告的公众号页面截图或 PacketTunnel 日志，定位具体接口。
