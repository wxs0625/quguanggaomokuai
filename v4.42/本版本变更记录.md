# v4.42 本版本变更记录

生成时间：2026-08-18
版本定位：在 v4.41 的精简范围基础上，修复汽水音乐 api3-lq 请求触发无网络提示，并补齐微博信息流广告净化。

## 问题核对

- 用户反馈汽水音乐可以正常播放歌曲，但出现“无网络连接”弹窗。
- v4.41 将 `api3-lq.qishui.com` 纳入后，把该主机的多个 `/luna/*` 请求直接返回 `reject-dict`；这类接口被客户端视为请求失败，是弹窗的直接风险点。
- 用户反馈微博已经没有开屏广告，但推文信息流中仍出现推广帖子。
- v4.41 只有微博域名拦截和直连规则，没有接入上游微博信息流响应脚本；同时 `[MITM]` 明确排除了微博主机，所以脚本无法处理推文 JSON。
- 本次没有提供汽水弹窗出现时的新代理数据库，因此汽水修复依据 v4.41 现有规则链和用户反馈，不把旧日志当作本次设备实测证据。

## 源码核对

- 上游 `fmz200/wool_scripts` 的微博模块包含 `weibo_main.js` 和 `weibo_ads.js`，分别覆盖首页时间线、卡片流、发现页、热搜、话题和详情广告。
- 上游微博脚本地址可正常获取；汽水规则仍保留 v4.41 已确认的 `api3-lq.qishui.com` 响应处理范围。

## 本次处理

1. 将汽水硬拒绝规则中的 `api\d+-lq` 收窄为 `api5-lq`，保留 api3 的正常 HTTP 响应，避免客户端将广告接口拒绝误判为无网络。
2. 为 `api3-lq.qishui.com/luna/ads/` 增加响应净化，仅删除广告载荷字段，保留正常响应状态和 JSON 外壳。
3. 保留汽水 api3 的 MITM 和歌曲页响应规则，不改变正常听歌链路。
4. 新增微博首页信息流、发现页、热搜、话题、评论和详情响应脚本，移除推文中的推广对象。
5. 移除微博相关 MITM 排除项并加入 `*.weibo.cn`、`*.weibo.com` 和 `weibo.com`，使新增响应脚本能够处理接口。
6. 所有新增脚本使用 `v442_` 标签；保留 v4.41 及之前版本目录和文件。

## 预期结果

- 汽水音乐 api3 主机不再因广告接口硬拒绝而触发“无网络连接”弹窗，歌曲播放保持可用。
- 微博开屏广告保持不变，首页推文及相关信息流中的推广帖子由响应脚本过滤。
- 闪动校园、抖音、网易云和其它软件规则不在本次改动范围内。
- 本地只能完成规则、脚本地址和语法静态校验，不能声称已在 iPhone 上实测通过。

## 继承的精简范围

- 继续使用 v4.23 用户精简范围，不恢复 v4.7 全量域名。
- 继续保留 v4.40/v4.41 的 YouTube、哔哩哔哩、网易云、汽水及其它已选 App 配置。
- 没有恢复用户未安装的软件模块，也没有删除旧版本。
