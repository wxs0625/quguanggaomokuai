# v4.54 本版本变更记录

生成日期：2026-08-22

## 版本目的

针对多个软件首次启动偶发出现开屏广告、后续启动不再出现且难以稳定抓取日志的问题，在 v4.53 基础上增加请求级兜底规则。

## 本次改动

1. 新增广告主机请求拦截。
   - 仅匹配主机名中明确包含 ad、ads、adserver、adservice、mobads、pangolin、doubleclick 等广告服务标识的请求。
   - 不使用全局 hostname = *，避免把正常业务请求一并拦截。

2. 新增开屏广告路径拦截。
   - 覆盖 splash、startupAd、openScreenAd、startpicture、launchAd、getAppSplash 等常见开屏接口名称。
   - 使用完整路径边界匹配，避免误伤 startupConfig、普通首页、搜索、推荐和播放接口。

3. 新增广告查询参数拦截。
   - 覆盖 adspace、adslot、adunit、launchAd、splash、openscreen 等明确广告位参数。
   - 只有 URL 明确含有查询参数时才匹配，不会拦截普通无参数请求。

4. 保留原有模块内容。
   - 未删除或覆盖 v4.53 及之前版本。
   - 保留原有各软件的去广告规则、网络例外和京东响应脚本。
   - 京东启动脚本继续引用 v4.54 目录内的同版本规则。

## 风险控制

- 未新增全局域名关键字拦截。
- 未把所有软件请求统一拒绝。
- 对全局新增的广告请求使用 REJECT 或 REJECT-DICT，尽量避免应用因广告请求失败弹出无网络提示。
- 广告接口名称与正常业务名称重叠时，仍需根据实际请求日志增加应用专属例外。

## 验证结果

- 已检查模块包含 URL Rewrite、Map Local、Body Rewrite、Script、Rule、MITM 六个配置段。
- 已检查京东脚本 URL 指向 v4.54。
- 已检查规则中不包含 hostname = *。
- 已完成广告主机、广告路径、广告查询参数的正反例静态检查。
- 当前环境没有 iPhone 和 Shadowrocket，无法替代真机完成所有软件的冷启动验证。
