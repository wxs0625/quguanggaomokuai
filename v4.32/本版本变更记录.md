# v4.32 本版本变更记录

生成时间：2026-08-16

## 本次问题

用户反馈 v4.31 仍有广告。前几版已经处理了脚本重名、MITM 前置，但仍可能因为大模块中 `[Rule]` 段有 2000 多行，导致关键的 `URL Rewrite`、`Map Local`、`Script`、`MITM` 段落在导入/执行时过于靠后，和单独模块的执行位置不同。

## 本版本判断

单独模块能去广告、集成后仍有广告，除了脚本重名外，还有一个高概率原因：单独模块的核心段落在文件前部，而集成模块把大量通用 Rule 放在最前，关键开屏规则被压到后面。本版不再继续盲加大量新域名，而是把关键执行段前置。

## 本版本改动

1. 新建 `v4.32/` 目录，不覆盖旧版本。
2. 模块名更新为：`全能去广告精简保留目标前置版 v4.32`。
3. 调整段落顺序为：
   - `[URL Rewrite]`
   - `[Map Local]`
   - `[Script]`
   - `[MITM]`
   - `[Body Rewrite]`
   - `[Rule]`
4. 将关键开屏规则放到整个文件最前面，避免被大段 Rule 压到后面。
5. 保留 v4.31 的规则来源：
   - 网易云音乐：用户附件 ddgksf2013 模块。
   - 转转、虎牙直播、腾讯视频、优酷：fmz200 分应用模块。
6. 保留 v4.31 的脚本名隔离：Script 重名为 0。
7. 保留目标 MITM 域名前置。
8. 不恢复 `通用广告字段净化.js`、`byte-clean` 或抖音联网相关改动。

## 新增前置兜底

本版额外把以下高频开屏接口放在 `[URL Rewrite]` 与 `[Map Local]` 第一屏：

- 转转：`getOpenScreen`、`getallpopwin`、`getConfigInfo`
- 虎牙直播：`live-ads.huya.com`、`cdnfile1.msstatic.com`、`business.msstatic.com`、`cdn.wup.huya.com`
- 腾讯视频：`vv.video.qq.com/(diff|get)vmind`
- 优酷：`un-acs.youku.com` 开屏 appinfo、`push.m.youku.com` 弹窗、`acs.youku.com` 弹窗/预加载
- 网易云音乐：`ad/loading/get`、`ad/loading/current`、`ad/get`、`sp/flow/popup/query`

## 验证记录

- 模块结构检查通过：`Rule`、`URL Rewrite`、`Body Rewrite`、`Map Local`、`Script`、`MITM` 均为单一段落。
- 段落顺序检查通过：`URL Rewrite`、`Map Local`、`Script`、`MITM` 均位于 `Rule` 之前。
- 模块头部检查通过：包含 `#!name`、`#!desc`、`#!author`、`#!homepage`、`#!category`、`#!arguments`。
- Script 重名检查通过：重复脚本名为 0。
- 风险残留检查通过：未发现 `/main/v4.25/`、`/main/v4.26/`、`通用广告字段净化`、`byte-clean`。
- URL Rewrite 语法检查通过：未发现 ` - reject` / ` - reject-dict` 旧式写法。

## 重要说明

如果 v4.32 仍然出现同一个 App 的开屏广告，那么基本可以确认：当前源模块和兜底接口都没有命中实际广告请求。下一步必须提供该 App 打开时的 PacketTunnel 日志，直接从日志中提取真实开屏域名/路径，否则继续猜规则收益很低。
