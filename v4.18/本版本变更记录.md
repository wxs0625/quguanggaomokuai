# v4.18 本版本变更记录

## 版本定位

- 版本：v4.18
- 日期：2026-08-13
- 文件：全能去广告修复版-Shadowrocket-v4.18.sgmodule
- 基线：v4.17/全能去广告修复版-Shadowrocket-v4.17.sgmodule
- 用户反馈：v4.17 仍然有闪动校园开屏广告。
- 目的：保留 v4.15 以后已经恢复的启动稳定性，继续处理被稳定版放开的广告 SDK 素材请求。

## 判断依据

- v4.17 已恢复 ad.shunchangzhixing.com 的 MITM，并空置 base/getAd，但开屏广告仍存在。
- 因此开屏广告很可能不只来自 shunchangzhixing，而是来自 v4.15 为稳定启动临时放开的第三方广告 SDK。
- 之前 v4.14 生效后的日志中，启动窗口出现过 GDT、穿山甲/GroMore、Sigmob、ubixioe、1rtb、Beizi、AdWangMai、adfunlink 等请求。
- v4.18 不回退这些域名的启动直连白名单，而是在响应层对广告素材/展示接口返回空数据。

## 本版本更改

- 保留 v4.15/v4.16/v4.17 的启动稳定白名单。
- 保持 USER-AGENT,ShanDong*,DIRECT 为注释状态，继续避免整 App 全放行。
- 在 [Map Local] 顶部新增 v4.18 广告 SDK 空响应规则：
  - mi.gdt.qq.com
  - v2mi.gdt.qq.com

  - api-access.pangolin-sdk-toutiao*/api/ad/union/sdk/stats 与 batch
  - log-api.pangolin-sdk-toutiao*
  - sf*-fe-tos.pglstatp-toutiao.com/obj/ad-pattern
  - lf-cdn-tos.bytescm.com/obj/static/ad
  - zlsdk.1rtb.net / sdk.1rtb.net req_ad
  - md/adx/entry ubixioe
  - ads/adtracker adfunlink
  - sdk/api-htp beizi
  - sdk/sdk-cfg/sdk-track adwangmai / 66mobi
- 在 [MITM] hostname 中恢复上述广告 SDK 域名的正向 MITM，并移除对应的负向排除项。
- 没有拦截 api.huachenjie.com、api-cfg.8ziben.com、hzjizhun.cn、getui/gepush、umeng/amap 日志域名等稳定性相关链路。

## 风险说明

- v4.18 比 v4.17 更积极，但仍是“响应层空数据”，不是整域名 REJECT。
- 如果 v4.18 不闪退且开屏广告减少，后续可继续按新日志收紧剩余展示域名。
- 如果 v4.18 重新闪退，说明某个第三方 SDK 的素材/配置接口也参与启动初始化，需要用新 PacketTunnel 日志回退对应接口。

- 已确认 v4.17 的 shunchangzhixing base/getAd 规则仍保留。
- 已确认 v4.15/v4.16 启动稳定白名单仍保留。
- 已确认相关广告 SDK 域名在 MITM hostname 中为正向项，不再被负向排除。
