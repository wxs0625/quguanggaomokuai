# v4.36 本版本变更记录

生成时间：2026-08-17  
版本定位：修复集成模块内部的 Shadowrocket 语法污染，不继续追加广告域名。

## 已确认的问题

1. v4.35 的 `[URL Rewrite]` 中有 493 条拒绝规则缺少 Shadowrocket 使用的 ` - ` 分隔符。
2. `[URL Rewrite]` 中混入 23 条 `request/response/json-jq/mock-body` 跨客户端写法，不属于 Shadowrocket URL Rewrite 格式。
3. `[Script]` 中混入 18 条没有脚本名称和 `type=` / `pattern=` 的 Loon 写法。
4. `[Map Local]` 中存在 1 条 JSON 内部引号未转义，可能导致该段解析中断。
5. 知乎解除链接限制的跳转顺序错误，已从 `替换地址 302` 改为 Shadowrocket 的 `302 - 替换地址`。

## 本次处理

- 将所有可识别的 reject 规则统一转换为 `正则 - reject类型`。
- 删除未在用户保留清单中的哔哩哔哩跨客户端坏行；没有恢复哔哩哔哩模块。
- 修复中国联通 Map Local JSON 转义，保留原返回内容不变。
- 保留 v4.35 的米游社、虎牙直播、腾讯视频、优酷规则内容和顺序。
- 保留 v4.35 的精简应用范围；没有增加额外域名清单。

## 为什么本版与 v4.35 不同

v4.35 已经把四个单独模块规则放在每个段落前部，但同一段落后面仍有不兼容语法。v4.36 处理的是整个段落能否被 Shadowrocket 完整解析的问题，而不是再次猜测广告接口。
