# v5.0 - 按需开关轻量版

- 日期：2026-08-13
- 文件夹：v5.0/
- 模块文件：v5.0/全能去广告按需开关版-Shadowrocket-v5.0.sgmodule
- 脚本文件：v5.0/按需去广告.js
- 用户反馈：v4.23 覆盖 700+ 软件，手机实际没有这么多 App，耗电量大；需要一个模块内按软件选择去广告。

## 核心改动

- 从 v4.23 的全量规则改为轻量按需规则，只保留当前反馈过且需要优先处理的闪动校园、百度网盘、微博、微信公众号，并保留酷安安全入口。
- 新增 #!arguments 中文参数，Shadowrocket 导入后可在“编辑参数”中看到中文软件名。
- 规则参数采用 REJECT=开启 / DIRECT=关闭，用于控制 [Rule] 中的软件广告域。
- 脚本参数采用 true=开启 / false=关闭，用于控制 [Script] 响应净化是否运行。
- 酷安默认保持 DIRECT，不恢复历史深度 MITM/响应改写，避免复现“无网络”。
- 通用开屏 SDK 默认 DIRECT，避免未安装 App 或非目标 App 被大范围误伤；需要更强开屏拦截时可手动改为 REJECT。

## 与 v4.23 的差异

- v4.23：约 5,500 条 [Rule]、1,500+ 条 [URL Rewrite]、700+ 软件全量覆盖。
- v5.0：只保留少量目标应用规则和 3 条响应净化脚本，减少未安装 App 的规则匹配。
- v4.23 的微信公众号净化逻辑合并进 v5.0 的 按需去广告.js，不再单独维护公众号脚本。
- v5.0 保持单模块结构，没有拆成多个软件模块。

## 使用方式

- 导入 v5.0 模块后，进入 Shadowrocket 模块详情页的“编辑参数”。
- 未安装的软件：把对应“规则”参数从 REJECT 改为 DIRECT，脚本参数从 true 改为 false。
- 酷安如只需要联网稳定，保持默认 DIRECT；只有确认要拦截热搜接口时再改为 REJECT。
- 如果闪动校园仍有开屏广告，再把 通用开屏SDK规则 从 DIRECT 改为 REJECT 测试。
