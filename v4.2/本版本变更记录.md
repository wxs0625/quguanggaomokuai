# v4.2 本版本变更记录

## 版本定位

v4.2 是中文命名发布版，同时保留一个闪动校园单独兼容测试模块。

## 本版本文件

- `全能去广告修复版-Shadowrocket-v4.2.sgmodule`
- `闪动校园兼容修复版-Shadowrocket-v1.1.sgmodule`

## 改动内容

- 将主模块发布文件改为中文命名。
- 将闪动校园单独测试模块改为中文命名。
- 将闪动校园相关接口从空 JSON 响应改为带状态字段的安全 JSON。
- 移除部分会抢先命中的广告 SDK 硬拦截，改由脚本或 Map Local 继续处理。

## 检查重点

- 本版本存在单独闪动校园模块，仅用于隔离测试。
- 正式使用时后续版本已改为单主模块发布，不再需要同时导入两个模块。
