# v4.40 本版本变更记录

生成时间：2026-08-18
版本定位：在 v4.39 的精简范围基础上，根据两份 2026-08-18 代理日志，定向修复网易云音乐和哔哩哔哩开屏广告。

## 问题核对

- README 对应的官方独立模块可正常获取：哔哩哔哩、网易云音乐和抖音模块均返回 `HTTP 200`。
- v4.38 只有哔哩哔哩域名规则，没有官方模块中的 `app.bilibili.com/x/v2/splash` 响应体清理规则。
- v4.38 网易云使用旧版 `ddgksf2013` 23 条脚本，未采用用户单独模块中的广告空响应和 `ipv4.music.163.com` 处理方式。
- v4.38 的共享广告规则直接拒绝 `i.snssdk.com`、`is.snssdk.com`、`security.snssdk.com`、`vas.snssdk.com`、`effect.snssdk.com` 和 `webcast-open.douyin.com`，会误伤抖音正常接口。
- 当前本地 PacketTunnel 日志日期为 2026-08-13，早于本次反馈，因此本版依据当前模块和官方源核对，不把旧日志当作本次设备实测证据。

## 日志确认

- 网易云 `proxy-2026-08-18-093730.db` 显示 `interface3.music.163.com/xeapi/ad/loading/bidget`、`/xeapi/ad/get`、`/xeapi/ad/config/get` 和 `/xeapi/ad/monitor/video` 均命中 `DOMAIN-SUFFIX,music.163.com,DIRECT`，没有命中原有 `eapi/ad` 空响应规则。
- 哔哩哔哩 `proxy-2026-08-18-094443.db` 显示开屏资源为 `upos-sz-static.bilivideo.com/...-1-SPLASH.mp4`，该资源已命中拒绝规则；同时 `app.bilibili.com` 的启动响应需要响应体规则，但集成模块的 `[MITM]` 缺少该主机，因此原有清空开屏字段规则未执行。

## 本次处理

1. 在 `[Map Local]` 新增 `interface`/`ipv4` 主机的 `xeapi/ad/*` 空 JSON 响应，覆盖日志确认的网易云广告加载、获取、配置和视频监测接口。
2. 在 `[MITM]` 补充 `app.bilibili.com`，使现有 `x/v2/splash/(list|show|event/list2)` 响应体清空规则真正生效。
3. 保留哔哩哔哩 `x/resource/peak/download` 与 `upos-sz-static...-1-SPLASH` 资源拦截；不新增日志未确认的哔哩哔哩域名。
4. 将网易云脚本标签从 `v439_` 更新为 `v440_`，同步修正模块、记录和自检中的版本标识。
5. 不修改抖音、闪动校园或其它软件规则，避免扩大本次影响范围。

## 预期结果

- 哔哩哔哩启动接口的开屏展示和事件列表由响应体规则清空，开屏视频资源继续被拒绝。
- 网易云日志确认的 `xeapi/ad/*` 广告请求返回空数据，正常 `xeapi` 歌曲、用户和播放接口不受影响。
- 抖音搜索记录、联想词和小部件规则保持 v4.39 状态。
- 本地只能完成规则、源文件和语法静态校验，不能声称已在 iPhone 上实测通过。
