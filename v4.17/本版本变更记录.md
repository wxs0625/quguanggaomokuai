# v4.17 本版本变更记录

## 版本定位

- 版本：v4.17
- 日期：2026-08-13
- 文件：全能去广告修复版-Shadowrocket-v4.17.sgmodule
- 基线：v4.16/全能去广告修复版-Shadowrocket-v4.16.sgmodule
- 用户反馈：v4.16 仍然有闪动校园开屏广告。
- 目的：保留 v4.15/v4.16 已经恢复的启动稳定性，只修正开屏广告 HTTPS 接口没有被本地映射命中的问题。

## 问题复核

- v4.16 已经恢复了 ad.shunchangzhixing.com/getAd 的 Map Local 空数组。
- 但是 v4.16 仍在 [MITM] hostname 中保留 -ad.shunchangzhixing.com 和 -*.shunchangzhixing.com。
- 因此 HTTPS 的 ad.shunchangzhixing.com/base/* 与 https getAd 不会被解密，本地 Map Local 对 HTTPS 广告接口无法生效。
- 之前日志里开屏阶段明确出现过：
  - https://ad.shunchangzhixing.com/base/877542
  - https://ad.shunchangzhixing.com/base/1829563
  - http://ad.shunchangzhixing.com/getAd/877542

## 本版本更改

- 保留 v4.15/v4.16 启动 SDK 直连白名单，避免回到闪退。
- 继续保持 USER-AGENT,ShanDong*,DIRECT 为注释状态，不再整 App 放行。
- 在 [Map Local] 顶部新增：
  - https?://ad.shunchangzhixing.com/base/数字
  - 返回 {"code":200,"msg":"success","data":{}}
- 保留 v4.16 的 getAd 空数组规则：
  - http://ad.shunchangzhixing.com/getAd
  - https?://ad.shunchangzhixing.com/getAd
- 在 [MITM] hostname 中：
  - 移除 -ad.shunchangzhixing.com
  - 移除 -*.shunchangzhixing.com
  - 新增正向 ad.shunchangzhixing.com
- 没有重新封禁 shunchangzhixing.com 整个域名，避免回到 v4.13/v4.14 前的 REJECT 闪退问题。

## 风险说明

- v4.17 比 v4.16 更可能去掉 HTTPS 开屏广告，但如果广告 SDK 对 base 空对象不兼容，仍可能影响启动。
- 这是小步版本：只处理 base/getAd，不动 hzjizhun、gromore、getui、umeng、amap、gdt 等稳定性白名单。
- 如果 v4.17 稳定但仍有开屏广告，需要新日志定位真实广告素材/展示接口，不能继续盲目扩大拦截。

- 已确认 [Map Local] 顶部存在 base 空对象规则。
