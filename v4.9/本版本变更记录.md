# v4.9 本版本变更记录

日期：2026-08-13

## 本版本文件

- `全能去广告修复版-Shadowrocket-v4.9.sgmodule`

## 改动背景

- 用户反馈：v4.8 后闪动校园有时卡在软件启动页，然后闪退。

## 改动摘要

- 从 `v4.8` 复制生成 `v4.9` 主模块文件。
- 闪动校园改为“启动稳定优先版”：暂停闪动校园相关 Map Local 响应体改写。
- 删除闪动校园启动阶段可能命中的 `ad.shunchangzhixing.com`、`open.e.kuaishou.cn`、`zlsdk.1rtb.net`、`sdk.1rtb.net` 本地响应改写。
- 从 MITM 主机列表中移除 `ad.shunchangzhixing.com`、`open.e.kuaishou.cn`、`open.e.kuaishou.com`、`zlsdk.1rtb.net`、`sdk.1rtb.net`，避免启动阶段 HTTPS 解密误伤。
- 从通用广告脚本匹配中移除 `open.e.kuaishou.com/rest/e/v3/open/univ`，避免与其它模块的 MITM 主机叠加后误触发。
- 继续保留 v4.8 的百度网盘开屏广告补强规则。
- 旧版本目录不删除，继续保留 `v4.0` 至 `v4.8`。

## 闪动校园修复说明

- v4.8 已移除主业务域名 `api.huachenjie.com` 的 MITM/Map Local 改写，但仍保留外部广告 SDK 的响应体改写。
- 闪动校园启动页仍可能等待广告 SDK 初始化结果；如果返回体结构或时序不符合 App 预期，可能卡启动页或闪退。
- v4.9 先暂停闪动校园相关响应体改写、对应 MITM 主机和快手开放广告脚本匹配，优先验证 App 能稳定打开。
- 如果 v4.9 打开稳定，再按单个接口逐条恢复广告规则，避免一次性改写多个启动接口。

## 百度网盘说明

- 本版本不回退百度网盘开屏广告补强规则。
- 若百度网盘仍显示旧开屏，优先清理 App 缓存或等待缓存过期。
