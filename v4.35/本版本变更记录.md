# v4.35 本版本变更记录

生成时间：2026-08-17  
版本定位：针对精简模块中仍有开屏广告的 6 个 App 做定向修复，不恢复未安装 App 的规则域名。

## 核对结论

1. 米游社、汽水音乐、纵横小说的去广告规则已经存在于 v4.34，但其 HTTPS 请求域名没有进入实际匹配清单，导致规则无法命中。
2. 腾讯视频在 v4.34 使用了从注释规则推导出的转换写法，与本地单独可用模块并不一致。
3. 优酷在 v4.34 对开屏接口使用整段拒绝或空响应；本地单独可用模块采用保留正常响应、只删除广告字段的方式，两者行为不同。
4. 虎牙规则基本完整，但 App 自带 HTTPDNS 请求可能绕过域名拦截；v4.35 只加入虎牙自己的 HTTPDNS 阻断，不加入通用大范围 HTTPDNS 列表。

## 本次改动

- 米游社：完整前置本地单独模块的 URL Rewrite 与 Body Rewrite，并补齐 3 个实际域名。
- 虎牙直播：重新前置 fmz200 单独模块全部规则，增加仅针对虎牙的 HTTPDNS URL 规则。
- 腾讯视频：替换为本地单独模块的完整 Rule、URL Rewrite 和 request 脚本；移除 v4.34 推导的 Body Rewrite 写法。
- 汽水音乐：完整前置本地单独模块的 URL Rewrite、Body Rewrite、Script，并补齐 5 类实际域名。
- 优酷：移除 v4.34 对 `un-acs` / `push` 的整段拒绝、空响应和旧脚本，改为本地单独模块的 DIRECT、广告域名拒绝和 JSON 字段删除规则。
- 纵横小说：完整前置本地单独模块的两条开屏/弹窗规则，并仅加入 `api1.zongheng.com`、`api2.zongheng.com`。
- 未改动抖音、闪动校园、酷安等其它 App 的既有规则。
