# v4.20 - 微博/酷安局部无网络稳定修复版

- 日期：2026-08-13
- 文件夹：v4.20/
- 模块文件：v4.20/全能去广告修复版-Shadowrocket-v4.20.sgmodule
- 本次依据：用户反馈微博部分页面提示无网络，酷安也出现类似提示。
- 基线版本：v4.19，保留 v4.19 对闪动校园和其他 App 的既有规则，不回退全局规则。

## 核心判断

- 微博和酷安都存在较多 HTTPS Body Rewrite、Map Local 和远程脚本改写。
- 这类深度改写依赖 MITM，容易在 App 接口变更、证书校验或返回结构变化时表现为局部“无网络”。
- 本版按稳定优先处理：微博/酷安业务域直连，并关闭对应深度改写，避免继续误杀正常接口。

## 本版改动

- 新增微博业务域直连：weibo.com、weibo.cn、weibocdn.com、sina.cn、sina.com.cn、sina.com、sinajs.cn、sinawap.com、sinaimg.cn、sinaimg.com、sinaalicdn.com、sinaaliyun.cn。
- 新增酷安业务域直连：api.coolapk.com、www.coolapk.com、coolapk.com。
- 注释微博相关 URL Rewrite、Body Rewrite、Map Local 和 Script 规则，避免局部页面返回空对象或脚本异常。
- 注释酷安相关 URL Rewrite、Body Rewrite 和 Script 规则，避免搜索、详情、首页、列表页面误判无网络。
- 从 MITM hostname 中排除微博和酷安核心域名，减少证书或 HTTPS 改写导致的异常。

## 验证结果

- v4.20 版本头已更新。
- 微博/酷安业务域 DIRECT 规则位于 Rule 顶部，优先级高于后续通用 REJECT。
- 微博/酷安相关深度重写已注释 50 条。
- MITM hostname 中已移除 api.coolapk.com、www.coolapk.com、weibo.com、*.weibo.com、*.weibo.cn 等正向项，并加入排除项。

## 风险说明

- 本版优先解决“无网络”提示，微博和酷安内部去广告效果会下降。
- 闪动校园相关 v4.19 规则未改动。
