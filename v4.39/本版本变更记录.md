# v4.39 本版本变更记录

生成时间：2026-08-18
版本定位：在 v4.38 的精简范围基础上，定向修复哔哩哔哩、网易云音乐开屏广告，以及抖音搜索和小部件网络异常。

## 问题核对

- README 对应的官方独立模块可正常获取：哔哩哔哩、网易云音乐和抖音模块均返回 `HTTP 200`。
- v4.38 只有哔哩哔哩域名规则，没有官方模块中的 `app.bilibili.com/x/v2/splash` 响应体清理规则。
- v4.38 网易云使用旧版 `ddgksf2013` 23 条脚本，未采用用户单独模块中的广告空响应和 `ipv4.music.163.com` 处理方式。
- v4.38 的共享广告规则直接拒绝 `i.snssdk.com`、`is.snssdk.com`、`security.snssdk.com`、`vas.snssdk.com`、`effect.snssdk.com` 和 `webcast-open.douyin.com`，会误伤抖音正常接口。
- 当前本地 PacketTunnel 日志日期为 2026-08-13，早于本次反馈，因此本版依据当前模块和官方源核对，不把旧日志当作本次设备实测证据。

## 本次处理

1. 新增哔哩哔哩 `app.bilibili.com/x/resource/peak/download` 拦截和 `x/v2/splash/(list|show|event/list2)` 响应体清理。
2. 删除网易云旧版 `ddgksf2013` 23 条脚本，改为官方单独模块使用的 6 条 `Keywos/rule` `wyres.js` 脚本。
3. 补充网易云广告接口、搜索广告接口空响应，以及广告素材域名规则；脚本覆盖 `ipv4` 和 `interface` 主机。
4. 在抖音规则最前放行 6 个被共享广告规则误拒的核心域名，保留后续广告路径和广告平台拦截规则。
5. 保持 YouTube 修复、用户精简 App 范围、其它软件规则和旧版本目录不变。

## 预期结果

- 哔哩哔哩启动接口返回空的开屏展示和事件列表，不影响普通启动响应。
- 网易云广告接口在 `interface` 与 `ipv4` 两类主机上统一处理，减少开屏广告偶现。
- 抖音搜索记录、联想词和小部件不再被上述核心域名规则直接拒绝。
- 本地只能完成规则、源文件和语法静态校验，不能声称已在 iPhone 上实测通过。

## 继承的精简范围根因

- 用户精简版 v4.23 的域名清单有 365 项。
- v4.36 的域名清单只剩 30 项，但规则段仍保留了大量已选 App 的响应处理规则。
- 这造成规则文本存在，但对应请求无法被处理，所以不止米游社、虎牙直播、腾讯视频、优酷，很多已保留 App 都恢复广告。
- v4.23 还有一个拼接错误的 `cupid.51job*.comhostname`，本版已修正为 `cupid.51job*.com`。

## 继承的精简范围处理

1. 以用户精简版 v4.23 的 365 项有效域名为基础恢复范围。
2. 合并 v4.36 已确认的六应用新增域名：米游社、虎牙直播、腾讯视频、汽水音乐、优酷、纵横小说。
3. 没有使用 v4.7 的 1000 多项全量域名。
4. 没有恢复用户未安装的软件模块。
5. v4.36 的 Rewrite、Map Local、Body Rewrite、Script 纯净语法全部保留。
